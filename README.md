# Pokémon Box Patcher

A GameCube ISO patching tool for **Pokémon Box: Ruby & Sapphire** (NTSC-U and PAL).

## Features

- **Universal Patch** — Applies the Universal Version patch to supported USA versions of Pokémon Box.
- **Adventure Mode Support** *(Optional)* — Adds support for Pokémon FireRed, LeafGreen, and Emerald in Adventure Mode.

## Requirements

- Python 3.8
- A supported Pokémon Box Ruby & Sapphire GameCube ISO.
- Your own legally obtained ROM dumps of Pokémon FireRed, LeafGreen, and/or Emerald if you want to use the optional Adventure Mode support.
